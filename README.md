# Simple Interest Calculator

## Project Description
This project is a simple interest calculator that calculates interest based on the principal amount, annual rate of interest, and time period in years.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual interest rate (percentage)
- Time period (years)

## Example
If the principal is 1000, the annual rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = 100
